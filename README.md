# A-Duplicate-Screened-Brain-Tumor-MRI-Dataset-Curation-Pipeline
Duplicate-screened curation pipeline for a Bangladeshi clinical brain tumor MRI dataset (5,941 images, 4 classes). MD5 + perceptual-hash de-duplication, stratified 70/15/15 split with content-hash leakage verification, and benchmarks across 7 CNN/ViT/ResNet/DenseNet architectures.
